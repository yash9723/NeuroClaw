# Ponytail Skill for OpenClaw

Enforces the 7-step decision ladder to keep code minimal, clean, and maintainable under rapid 30-hour sprint constraints.

## Directives
1. **Zero Unnecessary Dependencies:** Prioritize native platform capabilities (`navigator.vibrate`, Web Speech, MediaDevices).
2. **Lean Architecture:** Files must not exceed 120 lines. Keep components modular and readable on a smartphone screen during Red Light.
3. **High Hackability:** Ensure all APIs are portable across laptop and mobile devices without hardcoded localhost boundaries.
